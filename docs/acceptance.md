# 播放器第一版验收

注意事项：

- 每条末尾标注承接它的测试层（`单测` `组件` `桌面e2e` `安卓e2e` `构建` `人工`），分层与位置见[技术架构 · 测试分层](architecture.md#测试分层)。按测试先行，先写出对应测试，再实现到测试通过。
- 视觉相关的条目对照 `design/preview/`（`node design/preview/serve.mjs` 后打开 `http://localhost:5178/desktop.html` 或 `mobile.html`）。
- 测试使用 `fixtures/music/` 的生成素材，不依赖 `assets/`。

## 验收标准

### 通用

- [ ] 应用不访问网络：安卓清单没有网络权限，Tauri 配置未开放网络能力 `构建`
- [ ] Windows 安装包不含曲库，体积不超过 15 MB `构建`
- [ ] mp3 和 ogg（Vorbis）都能解码播放 `单测`
- [ ] mp3 和 ogg 的内嵌封面能读出；没有封面时显示歌名首字的字封，同一首歌颜色固定 `单测` `组件`

### 导入与播放列表

- [ ] 文件名“歌手、歌手 - 歌名 (版本)”解析出歌手和歌名；没有“ - ”时歌手为“未知歌手”，整个文件名作歌名 `单测`
- [ ] 歌曲和 `.lrc` 一起选择时，按去掉扩展名的文件名（忽略大小写和首尾空格）自动配对 `单测`
- [ ] 只选 `.lrc` 时补给列表中的同名歌曲；没有同名歌曲的歌词不加入列表 `单测`
- [ ] 再次导入同名歌曲时替换原条目，列表不出现重复 `单测`
- [ ] 导入整个文件夹时包含子文件夹中的歌曲和歌词 `单测`
- [ ] 导入完成只显示一句结果（如“已导入 12 首，10 首有歌词”）和“去听歌”；此时“去听歌”是唯一的主按钮 `组件`
- [ ] 点“去听歌”关闭导入界面，列表定位到第一首导入的歌曲 `组件` `桌面e2e`
- [ ] 从列表移除歌曲只移出列表，磁盘上的文件保留 `单测` `桌面e2e`
- [ ] 移除正在播放的歌曲时，接着播放列表中的下一首 `单测`
- [ ] 播放无法读取的文件（被移动或删除）时给出提示并跳到下一首 `单测` `组件`
- [ ] 重启后恢复播放列表及顺序、上次的歌曲（暂停状态）、播放模式和音量 `单测` `桌面e2e`

### 播放

- [ ] 播放、暂停、上一首、下一首可用；当前歌曲播放超过 3 秒时，“上一首”回到本曲开头 `单测`
- [ ] 顺序播放：最后一首播完后停止 `单测`
- [ ] 列表循环：最后一首播完后从第一首继续 `单测`
- [ ] 随机播放：下一首不会连续选中当前这首 `单测`
- [ ] 单曲循环：播完重新播放本曲 `单测`
- [ ] 单曲播放：播完本曲后停止 `单测`
- [ ] 上一首、下一首按列表当前顺序（包括拖动排序后的顺序） `单测`
- [ ] 倍速 0.5–1.5（步长 0.1）改变时长、不改变音高 `单测`
- [ ] 升降调 -6 到 +6 个半音改变音高、不改变时长 `单测`
- [ ] 进度条悬停显示该位置时间；拖动时时间实时跟随，松开才跳转 `组件`

### 歌词

- [ ] LRC 支持一行多个时间标签、两位或三位小数、`[offset]` `单测`
- [ ] 歌词不是合法 UTF-8 时按 GBK 解码 `单测`
- [ ] 没有歌词或歌词为空时显示“纯音乐，请欣赏”，不显示频谱或“没有找到歌词” `组件`
- [ ] 当前行随播放高亮，并自动滚动到歌词区中部偏上 `组件`
- [ ] 手动滚动歌词后暂停自动跟随，停止操作几秒后恢复 `组件`
- [ ] 点击某行歌词跳转到该行时间 `组件`

### 桌面端

- [ ] 无侧边栏；背景取自封面颜色；左上显示封面、歌名、歌手；歌词左对齐，当前行加粗白色 `人工`
- [ ] 播放队列面板：标题“播放队列”、共 N 首、搜索、“+”导入；每行显示序号、封面、歌名、歌手、时长 `组件`
- [ ] 一个按钮在封面行和紧凑行（“02 歌名 - 歌手 03:26”）之间切换；正在播放的行用跳动的均衡条代替序号 `组件`
- [ ] 搜索不区分大小写并高亮匹配；× 清空，“取消”或 Esc 关闭搜索 `组件`
- [ ] 双击行或按 Enter 播放该行 `组件`
- [ ] 按住行拖动可调整顺序：移动超过几像素才开始拖动（双击仍可播放），其余行让位，靠近边缘自动滚动；Alt+↑/↓ 也能调整；搜索时不能排序 `组件` `桌面e2e`
- [ ] 收起队列时歌词滑到窗口中间并居中，展开时回到左侧 `组件` `人工`
- [ ] 底栏与窗口同一背景；左侧封面、歌名/歌手、“01:01 / 02:59”；中间播放模式、上一首、播放、下一首、音效；右侧“词”、队列、音量 `组件`
- [ ] 进度条是底栏上沿贯穿窗口的细线 `人工`
- [ ] 音量为竖向弹出滑块并显示百分比，方向键可调节 `组件`
- [ ] 焦点不在输入框、按钮或滑块时空格键播放/暂停；进度条获得焦点时 ←/→ 后退/前进 5 秒 `组件`
- [ ] Esc 关闭弹层和导入对话框 `组件`
- [ ] 音效弹层含升降调和倍速两个滑块，中点为“正常”，可一键恢复正常 `组件`
- [ ] 导入对话框：“导入音乐”、拖放区“把歌曲拖到这里”、“选择歌曲”（主按钮）和“导入整个文件夹”；×、Esc 或点击外部关闭 `组件`
- [ ] 把歌曲文件拖进拖放区即可导入 `桌面e2e`
- [ ] 点“词”打开桌面歌词：透明、置顶、可拖动的独立窗口，两行交替显示，当前行按进度着色；前奏时第一行显示歌名，第二行预告第一句 `桌面e2e` `人工`

### 安卓端

- [ ] 首页即播放列表：右上角搜索和“+”；没有页面标题、筛选标签和底部标签栏；每行末尾有 × `组件`
- [ ] 正在播放的行只用强调色文字标出，封面上显示均衡条 `组件`
- [ ] 播放页控制依次为播放模式、上一首、播放、下一首、播放列表，按钮下没有文字 `组件`
- [ ] 切换播放模式时在屏幕中间偏下显示深色轻提示，自动消失 `组件`
- [ ] 进度条上方的 ⋮ 打开升降调/倍速面板（无标题、无“恢复正常”）；倍速不为 1.0 时显示如“1.2X” `组件`
- [ ] 播放列表按钮打开底部弹层：只有“播放列表 (N)”标题，点击弹层外关闭；每行封面、歌名/歌手两行、× `组件`
- [ ] 播放页背景为模糊加暗的封面；歌词当前行不放大 `人工`
- [ ] 播放页有飘落旋转的六角雪花，在文字之后，到控制区上方淡出；系统开启减少动态效果时关闭，页面不可见时停止动画 `组件` `人工`
- [ ] 导入页：返回、音乐图标、“导入音乐”、大号主按钮“选择歌曲”（歌曲和歌词一起选）、次要按钮“导入整个文件夹”，没有说明文字 `组件`
- [ ] 通过系统文件选择器导入的歌曲在重启应用后仍能播放 `安卓e2e`
- [ ] 切到后台或锁屏后继续播放；通知栏可播放/暂停、上一首、下一首 `安卓e2e`
- [ ] 来电或其他应用占用音频、耳机拔出时暂停 `安卓e2e`
