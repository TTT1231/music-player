# music

离线本地音乐播放器，支持 Windows 桌面和安卓：导入歌曲和同名 `.lrc` 歌词，自动配对，大字滚动歌词。

- 完全离线，不需要账号，不联网下载任何内容。
- 歌曲和歌词一起选，按文件名自动配对；没有歌词的歌曲显示“纯音乐，请欣赏”。
- 五种播放模式，可调升降调和倍速。
- 桌面端有可拖动的桌面歌词；安卓端支持后台和锁屏播放。
- Windows 和安卓都可以自建歌单，从「全部音乐」选择歌曲加入。
- Windows 可右键删除自建歌单，歌单里的歌曲仍保留在「全部音乐」。

Windows 导入后，音乐和歌词位于所选安装目录的 `assets/music` 和 `assets/lyrics`。安卓使用应用私有数据目录，卸载应用会清除其中的曲库。导入成功后，播放器会尝试移走源文件。从「全部音乐」确认移除歌曲时，会删除曲库中的音乐和配对歌词。从自建歌单或播放队列移除时，只移出该列表中的歌曲。
